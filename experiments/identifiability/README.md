# identifiability

Identifiabilité : ce que chaque source de données apporte, indice de débit de base observé, plafond de percolation préféré par station.

| script | rôle |
|---|---|
| `identifiabilite_indice_base.py` | Quelles covariables prédisent l'indice d'écoulement de base d'une station |
| `indice_base_observe.py` | Indice d'écoulement de base MESURÉ sur les hydrogrammes observés |
| `information_de_la_neige.py` | Combien de contraintes INDÉPENDANTES chaque source de neige apporte-t-elle |
| `information_des_donnees.py` | Combien de directions indépendantes TOUTES les observations portent-elles ensemble |
| `plafond_prefere.py` | Plafond de percolation préféré par station, et ce qui le prédit |

Ces fichiers viennent de `.runs/quebec`, rangés le 28 octobre 2026. Ceux qui importent le pilote ou ses chargeurs suivent leur nouvel emplacement dans le paquet.
