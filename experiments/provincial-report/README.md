# provincial-report

Rendu du rapport et de la présentation provinciaux. Essi lance ce script à la main ; il ne se lance pas automatiquement.

| script | rôle |
|---|---|
| `render.py` | Rend la presentation et le rapport provinciaux avec le bon interpreteur |

Ces fichiers viennent de `.runs/quebec`, rangés le 28 octobre 2026. Ceux qui importent le pilote ou ses chargeurs suivent leur nouvel emplacement dans le paquet.
