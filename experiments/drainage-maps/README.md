# drainage-maps

Cartes de drainage : croisement avec le SIH et reconstruction de la classe de drainage par apprentissage.

| script | rôle |
|---|---|
| `croiser_sih.py` | Épaisseur et nature des dépôts meubles d'après les puits du SIH, croisées par tronçon |
| `reconstruire_drainage.py` | Reconstruction d'une carte de la classe de drainage de terrain, a partir de tout |

Ces fichiers viennent de `.runs/quebec`, rangés le 28 octobre 2026. Ceux qui importent le pilote ou ses chargeurs suivent leur nouvel emplacement dans le paquet.
