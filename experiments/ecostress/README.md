# ecostress

Téléchargement des produits ECOSTRESS (script non suivi par git).

| script | rôle |
|---|---|
| `ecostress_download.py` | Télécharge les scènes ECOSTRESS (ET PT-JPL et LST) au-dessus de la Montérégie |

Ces fichiers viennent de `.runs/quebec`, rangés le 28 octobre 2026. Ceux qui importent le pilote ou ses chargeurs suivent leur nouvel emplacement dans le paquet.
