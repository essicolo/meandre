# Archive des scripts d'épreuve

Scripts de `.runs/quebec`, `.runs/slso`, `.runs/slso-od` et `.runs/stfran` qu'aucun autre fichier du dépôt ne nomme (ni import, ni script de lancement, ni registre, ni documentation) et dont le dernier commit est antérieur au 1er septembre 2026. Déplacés le 8 octobre 2026 pour que les dossiers de travail ne portent que les outils vivants. Rien n'est supprimé : l'historique git garde chaque fichier à son ancien chemin, et un script retrouve sa place par `git mv`.
